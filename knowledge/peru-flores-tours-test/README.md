# Peru Flores Tours Test

Proyecto para pruebas y desarrollo de funcionalidades relacionadas con el sitio web de Peru Flores Tours en Odoo.

## Objetivos

- Verificar la conexión y acceso a modelos de website.
- Probar la carga y visualización de productos/servicios de tours.
- Validar configuraciones de ecommerce y website.

## Scripts

| Script | Descripción |
|--------|-------------|
| `test_website_connection.py` | Lista los sitios web configurados en la instancia. |

## Ejecución

```bash
./run-knowledge.sh knowledge/peru-flores-tours-test/test_website_connection.py
```
