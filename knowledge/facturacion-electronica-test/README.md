# Pruebas de Facturación Electrónica

Este proyecto contiene scripts y configuraciones para validar el módulo de facturación electrónica en la instancia de pruebas de Odoo.

## Próximos Pasos (Sugeridos)

2. Crear un script para forzar el envío de una factura de contingencia y validar los XML/CDR.
