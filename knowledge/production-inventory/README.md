# Production Inventory

Proyecto dedicado a la gestión y análisis del inventario de producción en Odoo.

## Propósito

- Automatización de ajustes de inventario.
- Sincronización de stock de producción.
- Reportes personalizados de movimientos.

## Scripts

- `test_connection.py`: Verifica la conexión con Odoo.

## Cómo ejecutar

Utiliza el script helper desde la raíz del proyecto:

```bash
./run-knowledge.sh knowledge/production-inventory/test_connection.py
```
